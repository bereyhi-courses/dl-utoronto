## How to Submit
We use [Crowdmark](https://crowdmark.com/). When submitting, please make sure to follow the instructions below. Note that these instructions are __very important__ for correction and investigation of your submissions. Deviation from these instructions could lead to up to __10% deduction (per item).__

On Crowdmark, please submit the answer of each question separately, following the steps below. Also, __make sure to complete AI Usage Attestation__ field. Please note that failure to meet the formatting can lead to mark deduction.

- For Written Questions, you can submit __handwritten or typed answers as a .pdf , .jpg or .png file.__

- For Programming Questions, please submit a __Notebook (.ipynb)__ file including __your code and all outputs__. Your Notebook should contain __all figures, diagrams and codes that are requested in the question.__ You should make sure that the __the code runs without error.__

- Please set the file name  __Lastname_Firstname_Assgn#_Question#.ipynb.__

- Please make sure to use the name that is displayed on the __Quercus account.__

- Please __make sure to complete AI Usage Attestation__ field, where you can explain to what extent you have used AI in completing your assignments.

The deadline is specified on the Assignment file. The deadlines are __very strict and cannot be extended__ for the sake of fairness.
